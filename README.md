Sobre mim

Sou Lippe, estudante e desenvolvedor em formação.

Atualmente estou focado em JavaScript, construindo minha base através de projetos próprios e experimentação.

Gosto de transformar ideias em software e, principalmente, entender o processo por trás de cada projeto — desde a primeira ideia até aquilo realmente funcionar.

Meu maior objetivo não é simplesmente aprender várias tecnologias.

É chegar ao ponto de conseguir olhar para uma ideia grande e pensar:
